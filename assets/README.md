# Assets Directory

- `logo.svg`: The active vector logo used in the header, footer, and brand markings.
- `favicon.svg`: The browser tab favicon.

### How to use your own custom logo:
1. Simply replace `logo.svg` in this folder with your custom SVG image, OR
2. If you have a PNG/JPG logo (e.g. `my-logo.png`), copy it here and update the `<img>` `src` in `index.html`.
